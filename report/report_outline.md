## 〇、一句话定位

**这是一份"工程实现型"报告，不是"算法研究型"论文。**

国一那本的证据：18 页里 6～7 页是文字，7 页是实物图和屏幕截图，**零代码、零长公式推导、零 RTL 描述**。评委看的是：做没做出来、指标硬不硬、框图清不清楚、有没有一个"巧劲"。

所以我们的写法是：**一条主线讲到底 + 每章配硬指标 + 关键处给一张"别人没有的图"**。

### 各部分要点

#### 第一部分 设计概述（3 页）
- **1.1 设计目的**：1 段。不要写"随着科技的发展"这种套话。直接写：8 麦圆周阵列 → 全 360° 声源定位 + 波束增强 + 声源识别，用于……
- **1.2 应用领域**：4 条，每条一句（会议记录/视频会议拾音、工业设备异响定位、安防异常声检测、教学演示）。
- **1.3 系统主要特点**：4 条 → ①全 360° 无镜像模糊；②宽带（477 Hz–4.1 kHz 八个频点融合）；③硬件实时（PL 单时钟域，30 Hz DOA）；④软硬协同（PL 硬实时 + PS 柔性 + PC 可视化）。
- **1.4 关键性能指标**：**表格，放最前面**。这是我们最硬的地方，不要藏在后面。
- **1.5 主要创新点**：3 条，见第六节。

#### 第二部分 系统方案（2 页）
- **2.1 总体架构**：图1。三段式（PL / PS / PC），标出两条 AXI-Stream、AXI4-Lite、千兆网。
- **2.2 关键设计决策**：这节是**论证力**，四条，每条"选 A 不选 B，因为……"：
  1. **为什么用圆周阵列**：直线阵有 ±90° 左右镜像模糊；UCA 全 360° 无模糊，代价是导向矢量随角度非线性。
  2. **为什么 8 个频点非相干融合**：单频栅瓣是驻波/阵元间距造成的，融合后夹角分辨率下降但稳健性大幅提升（配图7）。
  3. **为什么 8 方位波束谱放 PS 算**：PL 资源已 54.8%，且 PC 只绘图不传输原始谱 → PS 是唯一合理位置（并说明：国一作品用的是**软核 M0**，我们用的是**硬核 A9**，同一思想、更高起点）。
  4. **为什么用网线回传而不是板载 HDMI**：见 `频谱显示.md` 第十节；一句话结论 = 帧缓冲放不进 BRAM + 视频时序开发量大 + PC 画图更灵活。

#### 第三部分 阵列信号处理（6 页）★ 核心
- **3.1 均匀圆周阵列模型**：α_i = i×45°，R = 50 mm，导向矢量 a_i(θ,f) = e^{j·kR·cos(θ−α_i)}，kR = 2πfR/c。配图3。
- **3.2 宽带非相干 MVDR**：8 个 bin 的空间谱相加，argmin → DOA。公式不超过 5 行，**不要推导**。
- **3.3 为什么是这 8 个 bin**：图5（频率轴 + kR 从 0.44 到 3.76）+ 一句话："kR 拉开才能让不同频率的栅瓣落在不同角度，相加时才互相抵消。"
- **3.4 为什么 8 bin 能压栅瓣**：**图6（本节杀手图）** —— 8 个 bin 各自的空间谱 + 融合后的总谱，四联图，一眼看出栅瓣被压平、主瓣仍对准。
- **3.5 自适应遗忘因子**：S=7（τ 1.34 s）保精度，信号消失切 SF=3（τ 84 ms）快释放；拍手拖尾 2.5 s → 0.3 s 而稳态精度不变。配图8（拖尾对比）。
- **3.6 FPGA 实现架构**：图4（PL 内部数据流）+ 图9（单 bin vs 8 bin 的 DOA 轨迹对比）。
- **3.7 资源受限下的算子复用**：表格，见第六节创新点 2。

#### 第四部分 波束成形与识别（3 页）

## 六、三条创新点（写法对齐国一）

### 1. 宽带非相干 8 频点 MVDR 融合 + 自适应记忆
- **问题**：单频 MVDR 的栅瓣是频率相关的，纯音下实测 DOA 在正确角附近乱跳；固定长记忆又导致拍手拖尾 2.5 s。
- **做法**：8 个频点（476.9～4100.8 Hz，kR 0.44～3.76）的空间谱非相干相加 → 主瓣相干增强、栅瓣去相关抵消。协方差不归零，用遗忘因子滑动（S=7，τ 1.34 s）；检测到信号消失时切 SF=3（τ 84 ms）。
- **效果**：连续声源 ±1～2° 稳定；拍手拖尾 2.5 s → 0.3 s，**稳态精度零损失**。

### 2. 资源受限下的算子时分复用（我们的"巧劲"）
- **问题**：8 频点 = 8 倍算力。若 `cov_to_q16` 例化 8 份（约 3500 LUT/份）= 28K LUT，XC7Z020 直接爆。
- **做法**：
  | 模块 | 份数 | 复用方式 |
  |---|---|---|
  | `cov_to_q16` | **1** | 前面加 8:1 的 R 选择 mux（36×64 bit） |
  | `mat_inv_8x8` | **1** | 序列 FSM，bin 0→7 依次复用 8 次 |
  | `steer_rom` | 8 | 36 BRAM（资源富余，不值得复用） |
  | `cov_accum` | 8 | 寄存器和 EMAC 串行 288 拍/快拍 |
- **效果**：把 **8 倍 MVDR 算力压进一片 7020**，LUT 仅 54.8%、BRAM 43.2%。
- **类比国一**：他们用 RLE 把传输量压 128 倍，我们用时分复用把资源压 1/8。**同一种"用架构换资源"的思路。**

### 3. PL / PS / PC 三段异构分工
- **PL**：I2S 采集 + 8 路 FFT + 协方差 + 8×8 求逆 + 扫角 + DAS + 波束成形 —— 全部在**单 50 MHz 时钟域**、硬实时、无 CPU 参与。
- **PS**：8 方位波束谱 + 声源类型识别 + 声纹识别 —— 柔性运算，改算法不用重综合。
- **PC**：只绘图。
- **两条独立数据流**：波束音频 97.7 kB/s（识别）+ 8 路复数谱 3.1 MB/s（可视化），各接一个 AXI DMA S2MM。
- **对比国一**：他们靠**软核 M0**（LUT 搭出来的 CPU）做调度；我们用**硬核 Cortex-A9**。同一套"软硬协同"思想，起点更高。

> 第 4 条可选特色（不进创新点，放 1.3 节）：**先粗后精双通道测向** —— DAS 宽带粗测（21 ms）锁方向，MVDR 窄带精测（30 Hz）报角度。

## 八、与国一作品对照（自知之明）

| 维度 | 国一作品 | 我们 |
|---|---|---|
| 硬件平台 | 紫光同创 PGL50H（国产）+ **自搭 M0 软核** | ZYNQ XC7Z020（**硬核 A9** + DDR3 + 千兆网） |
| 题目性质 | 便携多功能仪器（信号源 + 示波器 + 逻辑分析仪） | 声学阵列测向 + 波束成形 + 识别 |
| 三大指标 | 210 MSa/s / 65 MSa/s / 200 MSa/s×8ch | 360° / ±1~2° / 30 Hz / 8 频点融合 |
| 算法深度 | 浅（每个模块"实现了"） | **深（MVDR 是核心，有对照实验）** |
| 工程完整度 | **强（3 块自制 PCB + 触摸 GUI + 脱离电脑）** | 弱（现成开发板 + 依赖 PC） |
| 巧劲 | PWM+RC 当精密 DAC，用三次 | 算子时分复用，压 8 倍算力 |
| 诚实度 | 无局限分析 | **主动写局限（我们更好）** |
| 可视化 | 4.3 寸 TFT-LCD，逐像素画波形 | PC 上位机，雷达图 + 语谱图（更漂亮，但需带电脑） |

**结论**：我们在"算法深度"和"可视化效果"上更强，在"硬件自制程度"和"脱机独立性"上更弱。**不要硬追自制 PCB**（时间不够），把软件侧完成度做满（报告 + 图表 + 实测视频）是更划算的投入。
