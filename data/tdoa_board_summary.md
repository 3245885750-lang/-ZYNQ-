## 5. 原始记录格式

`data/tdoa_board_YYYYMMDD.csv`：

```csv
trial,true_deg,clap_idx,display_deg,error_deg,lowconf,status,notes
1,0,1,1,1,0,0x7,first clap
2,0,2,-1,-1,0,0x7,
...
```

字段说明：

| 列 | 含义 |
|---|---|
| `trial` | 第几次拍手 |
| `true_deg` | 真实方位（量角器/地贴） |
| `clap_idx` | 同一方向第几次 |
| `display_deg` | 板上显示角度（已含 +180° 偏移） |
| `error_deg` | `display_deg − true_deg`，按 ±180° 归一化 |
| `lowconf` | `0x54` bit1 |
| `status` | `0x54` 原值 |
| `notes` | 环境/异常 |

## 7. 边界

- 本表只对当前 bit/ELF/阵列/房间有效；
- 换麦克风、换线序、换阵列半径后必须重测；
- 强混响、多声源、非平面声源不在本表覆盖范围内。
