# data —— 上板实测数据

全部为本项目在真实板卡上采集的角度序列，用于分析测向行为与回归验证。
这些文件是「固定方位拍手、输出角度跳变」排查的直接证据，也是
`sim/model/` 中逐位回放脚本的输入。

## 列定义

大多数文件：

| 列 | 含义 |
|---|---|
| `t_s` | 时间，秒（采样周期约 0.021 s） |
| `type` | 通道：`M` = MVDR 精测，`D` = DAS 粗测（无则全是 M） |
| `deg` | 板上输出的角度，0–359 |
| `pwr_hex` / `pwr_dec` | 目标频点能量（十六进制 / 十进制） |
| `mot` | 运动检测标志（1 = 检测到运动，此列部分文件没有） |

`clap_log_20261101.csv` 是原始串口格式，列名未整理：

| 列 | 含义 |
|---|---|
| `t` | 时间，秒 |
| `M` | 通道标识 |
| `deg` | MVDR 角度 |
| `?` | 预留列，恒为 0 |
| `E` | 能量（十六进制） |
| `V` | 有效标志 |

### clap_log 说明了什么

逐帧看：第 0–21 ms 还在旧方向（52°），第 42 ms 跳到 140° 并稳定在 140–142°，
从 0.504 s 起能量从 0x097B 掉到 0x0054（约 12 dB），角度开始漂到 137→144→147。

结论：**峰值帧是稳定的，漂移发生在能量衰减之后**——此时协方差里已没有信号，
门控却仍在接受新的噪声估计。这就是「峰值相对门限 + 窗口内禁用强制放行」
这两个改动的依据。详见 `report/doa_jump_investigation.md` 第 8.7.18 节。

## 使用

```bash
python sim/model/analyze_doa_csv.py data/circle_v5.csv
python sim/model/plot_circle.py data/circle_v5.csv
python sim/model/sim_clap_smooth.py data/clap_log_20261101.csv
```

## 采集条件

- 板卡：正点原子领航者 ZYNQ-7020，8 × INMP441 圆周阵列（R = 50 mm）；
- 声源：手机外放白噪声 / 拍手 / 人声；
- 采样：PS 轮询 AXI-Lite 寄存器，约 21 ms 一条；
- 角度为板上显示值，含 +180° 安装偏移（模型角 = 显示角 − 180°）。

## 注意

- 数据是**角度序列**，不含原始音频，不能用来复算 MVDR 谱；
- `pwr` 是定点能量，不同录制之间不可直接比较绝对值；
- 上表中的 CSV 采集于 2026-10-28 的基线 bit；`src/pl/rtl/` 的 TDOA 开发版
  目前只有 RTL 逐位回放结果（`sim/results/tdoa_replay_summary.md`），
  上板数据按 `data/tdoa_board_summary.md` 采集后单独记录，不要混在同一张表里。
