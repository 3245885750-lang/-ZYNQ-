# 协方差矩阵 EMA 与对角加载

## 适用场景

MVDR / MUSIC 类测向在板上表现异常：方向漂移、纯音下乱跳、声源消失后角度
长时间不回零、旋转声源轨迹滞后。这类问题多数不在扫角模块，而在协方差的
估计方式上。

## 使用方法

### 1. 先判断是「记忆太长」还是「秩亏」

- **记忆太长**：声源已经移动或停止，角度还在原地停留数秒。看角度随时间的
  衰减时间常数，与 EMA 的 `τ ≈ 2^S` 个快拍对比。
- **秩亏**：矩阵接近奇异，求逆结果数值爆炸，空间谱出现针状峰或全平。
  用对角加载（`R + λI`）或重建（见下）验证。

### 2. EMA 参数选择

```
acc ← acc − (acc >>> S) + m
```

| S | 时间常数 | 用途 |
|---|---|---|
| 7 | ≈128 快拍（1.34 s） | 静止声源，精度优先 |
| 3 | ≈8 快拍（84 ms） | 运动/无信号，快速释放 |

关键点：**累加器不归零**，只在复位时清零。块平均会在块边界产生阶跃，
旋转声源的轨迹会一格格跳。

### 3. 秩亏的处理顺序

1. 先确认快拍数 K 是否足够（K ≥ 阵元数才满秩，本项目 K=2，靠 EMA 累积）；
2. 用对角加载 `R + λI`，λ 取对角线均值的固定比例；
3. 若加载后仍有针状峰，检查是否所有 bin 都被同一强单音占据；
4. 最后才考虑换估计器（前向-后向平均等）。

### 4. 验证

```
sim/model/sim_clr_check.py    # 对角加载/重建的数值检查
sim/model/sim_clr_seq.py      # 序列行为
sim/model/sim_evt_int.py      # 能量瞬态与记忆切换

```

## 已验证效果

- 8 bin 融合 + EMA S=7：连续声源实测 ±1–2°；
- 信号消失切 S=3：拍手拖尾从约 2.5 s 缩短到约 0.3 s，稳态精度不变；
- 对角加载与 CLR 重建按 `CLR_DEG=30`、`CLR_LD=4` 配置后，求逆不再出现数值异常。

## 失效条件

- 声源是**纯音**且只落在一个 bin 时，8 bin 融合退化为窄带，栅瓣无法靠融合消除；
  这是原理限制，不是参数问题。
- K 太小且 SNR 太低时，EMA 来不及收敛，任何 S 都救不了。
- 对角加载 λ 过大会压平主瓣，导致分辨力下降；需要按对角线量级标定。
